# Portfolio - Simple Project 🌐

My first web page, built using **only HTML and CSS**. This is a simple personal portfolio website showcasing my introduction, interests, projects, and a contact form.

## 🔗 Live Demo

👉 [View Live Site](https://uthragiri2005.github.io/Portfolio-simple-project/)

## 📸 Pages

- **Home (`index.html`)** — Introduction, About Me, Interests, and Projects section.
- **Contact (`contact.html`)** — A contact form built with an HTML `<table>` layout, including Name, Email, and Message fields with a Submit button.

## ✨ Features

- Fully responsive layout using pure HTML5 and CSS3
- About Me section with a short bio
- Interests list (Coding, Photography, Reading)
- Projects showcase (Amazon E-commerce Clone, Travel Website)
- Contact page with an HTML form structured using a table
- Social media links (Instagram, LinkedIn)
- Simple navigation between Home and Contact pages

## 🛠️ Built With

- HTML5
- CSS3

## 📁 Project Structure

```
Portfolio-simple-project/
├── index.html      # Home page
├── style.css       # Stylesheet for the site
└── contact.html    # Contact page with form
```

## 🚀 Getting Started

To run this project locally:

```bash
git clone https://github.com/uthragiri2005/Portfolio-simple-project.git
cd Portfolio-simple-project
```

Then simply open `index.html` in your browser.
